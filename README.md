# 英姐蔬果商行 GitHub Pages V1
1. 把全部檔案上傳 GitHub repository，Settings → Pages → Deploy from branch → main/root。
2. 建立 Firebase 專案與 Firestore。
3. 把 Firebase Web App 設定填入 firebase-config.js。
4. 後台網址為 /admin.html，預設密碼 168168，請修改。
5. 預設 10 種蔬菜：高麗菜、青江菜、空心菜、小白菜、菠菜、青椒、洋蔥、紅蘿蔔、馬鈴薯、白蘿蔔。
6. 價格可由後台修改。GitHub Pages 是靜態主機，因此商品與訂單使用 Firebase Firestore 同步。
